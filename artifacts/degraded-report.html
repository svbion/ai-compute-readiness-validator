🧮 Score Transparency

The readiness score is calculated using transparent category weights adjusted proportionally for missing or unavailable layers:

Score = Sum(Category_Score * Weight) / Total_Active_Weight
  • Category Scores: 100% for Passed checks, 50% for Warnings, 0% for Failed checks.
  • Unavailable Filters: Fully skipped/unavailable categories are excluded entirely, with active weights scaled up to total 100% proportionally.
  • Critical Override: If a CRITICAL check fails, the cluster is barred from "Ready" classification regardless of score.
